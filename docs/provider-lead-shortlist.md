- Handyman: start with `MK Handyman London LTD`, `London Handyman Pro`, `TaskMan of London`
- Pest control: start with `Bugwise Pest Control`, `Pest Mortem Pest Control`, `Beaver Pest Control`
- Waste removal: start with `The London Removal Company`, `Terra Waste`, `One Waste Clearance`

- Garden maintenance: start with `Bloomin Marvellous`, `MK Landscapes`, `Gardenio`

## Practical Recommendation

- First outreach batch: `20-25` leads only
- Mix: `12-15` companies + `8-10` small teams
- Prioritise categories in this order: `Cleaning`, `Handyman`, `Pest control`, `Waste removal`, then `Furniture assembly`, `Garden`
- Use your own DB first before buying more leads or posting on Indeed
- Use Indeed only if you want to recruit individuals for cleaning / handyman rather than partner with existing businesses
